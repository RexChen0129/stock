# BMI and Stock Analysis System

This project contains tools for BMI calculation and stock analysis.

## Files

- `app.py`: Main application script
- `bmi_system.html`: BMI calculation web interface
- `bmi_system.py`: BMI calculation backend
- `stock_system.html`: Stock analysis web interface
- `stock_module_v2.py`: Stock analysis module
- `stock.py`: Stock-related utilities
- `stock_gemini.html`: Additional stock interface

## Usage

Open `index.html` in your browser to access the main menu.
